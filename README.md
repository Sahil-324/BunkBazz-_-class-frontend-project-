#BunkBazz India: Tourism Website
A simple, responsive tourism website showcasing three Indian states:
Rajasthan, Uttar Pradesh, and Haryana.
#Features
- Mobile-first, responsive layout inspired by the BunkBazz reference
  design
- Hero section with a call-to-action
- Hamburger navigation menu
- Three state columns featuring famous tourist attractions
- Keyboard-friendly navigation: press Escape to close the menu
#Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts --- Plus Jakarta Sans

#Run Locally
1. Download or clone the project.
2. Open the project folder.
3. Open index.html in your browser.
No build tools or package installation are required.
#Images
The current images are simple SVG illustrations rather than photographs.
To use real photographs:
1. Add the image files to assets/images/.
2. Update the relevant image paths in index.html.
3. Use images that you own or are licensed for reuse, such as suitable
   images from Unsplash or Wikimedia Commons.
